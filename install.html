How to install

From download to playing

No experiments to turn on and no dedicated server needed. Pick your setup below. Stuck? Open a ticket and our team helps you set it up once, for free.

Single-player / LAN world

  1. Double-click the .mcaddon file. Minecraft opens and imports it. (Or: Settings → Storage → Import.)
  2. Open your world → Edit → Behavior Packs → Available → activate the Zenith pack.
  3. Ability Weapons also has a Resource Pack. Activate it under Resource Packs (Minecraft usually does this for you).
  4. Play, then follow the pack's guide. Setup always starts with /<pack>:setadmin @s true.

Realm

  1. Import the .mcaddon on your device as above.
  2. Make or open a world on your device, activate the pack(s), and do the setup (spawns, arenas and so on).
  3. Realm settings → Replace world → pick that world. The packs upload with it.
  4. Members download the packs automatically when they join.

Dedicated / hosted server (BDS)

  1. Rename the .mcaddon to .zip and extract it. You get a …_BP folder (and a …_RP for Ability Weapons).
  2. Upload …_BP to behavior_packs/ and …_RP to resource_packs/ on your server.
  3. Add them to your world's world_behavior_packs.json / world_resource_packs.json (uuid + version from each manifest.json). Many hosts have an "addons" button that does this for you.
  4. Restart the server.

Requirements

  • Minecraft Bedrock Edition 1.26.50 or newer.
  • No experiments needed. Cheats only need to be on for operator commands like setadmin.
  • Works together: install any combination of Zenith packs, and they detect each other.

Troubleshooting

"Unknown command"

The pack isn't active on this world, or the world needs reopening after adding it. Commands always include the pack prefix, e.g. /zenith_ffa:menu.

Floating leaderboards don't appear

Reopen the world once after adding the pack, then place them again from the admin panel.

"No permission" in the admin panel

An operator has to run /<pack>:setadmin <you> true first.

Something else

Turn on Settings → Creator → Content Log GUI, reproduce the problem, then send a screenshot of the red line in a Discord ticket. Fixes are free during your update period.
